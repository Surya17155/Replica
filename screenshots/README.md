# Screenshots Directory

Store your application UI screenshots in this folder.

### File Naming Convention
To keep 30, 50, or 100+ screens organized and sequentially tracked, name your screenshots with a numeric prefix and descriptive snake_case name:

```text
screenshots/
├── 01_home_feed.png
├── 02_video_watch.png
├── 03_channel_profile.png
├── 04_search_results.png
├── 05_playlist_view.png
└── ...
```

### Supported Formats
- `.png` (Recommended for crisp vector/raster UI details)
- `.jpg` / `.jpeg`
- `.webp`
